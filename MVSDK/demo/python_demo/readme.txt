mvsdk.py:	相机SDK接口库（参考文档 WindowsSDK安装目录\Document\MVSDK_API_CHS.chm）

grab.py: 使用SDK采集图片，并保存到硬盘文件
cv_grab.py: 使用SDK采集图片，转换为opencv的图像格式




mvsdk.py:
Thư viện giao diện (API) của SDK camera
(tham khảo tài liệu tại: WindowsSDK安装目录\Document\MVSDK_API_CHS.chm
→ Thư mục cài đặt WindowsSDK \ Document \ MVSDK_API_CHS.chm)

grab.py:
Sử dụng SDK để thu nhận (capture) hình ảnh và lưu vào file trên ổ cứng.

cv_grab.py:
Sử dụng SDK để thu nhận hình ảnh và chuyển đổi sang định dạng ảnh của OpenCV.
